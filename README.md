# AgileBoardLab

## Lab Title
**Lab 02: Agile Project Board, User Stories and Team Workflow**

## Project Overview
This project uses an Agile project board to organize and track user stories for a Library Book Search system. The board helps manage tasks, monitor progress, and understand how work moves through different stages of development.

## User Stories
The project includes the following five user stories:

1. **US-01:** Search books by title
2. **US-02:** Search books by author
3. **US-03:** Search books by subject
4. **US-04:** View book details
5. **US-05:** Handle searches with no results

Each user story includes a description and acceptance criteria to explain the expected functionality.

## Team Roles and Responsibilities
- **Project Board Manager:** Organizes the project board and tracks task progress.
- **User Story Owner:** Reviews the requirements and acceptance criteria for each assigned story.
- **Developer:** Plans and completes the technical tasks.
- **Reviewer:** Checks completed work against the acceptance criteria.

*Note: These are the project roles. Assign actual team members or GitHub usernames if your instructor requires them.*

## Workflow
The project uses the following workflow statuses:

1. **Backlog:** Stories that have been identified but are not ready to begin.
2. **Ready:** Stories that are ready to be worked on.
3. **In Progress:** Stories currently being worked on.
4. **Review:** Stories awaiting review.
5. **Done:** Stories that meet the completion requirements.

## Technical Tasks
Technical tasks are added to selected user stories to break the work into smaller, manageable steps. These tasks help clarify implementation and testing activities.

## Definition of Done
A user story is considered complete when:

- Its acceptance criteria have been met.
- The required technical tasks have been completed.
- The work has been checked against the requirements.
- Any required testing has been completed.
- The issue and project board status have been updated.

## Conclusion
This project demonstrates how Agile user stories, acceptance criteria, technical tasks, and a project board can help organize software development work and track progress throughout a workflow.
